# Security Policy

## Supported Versions

Security updates are provided for the latest release of this project.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately using GitHub Security Advisories:

https://github.com/flynn33/forsetti-Jamf-Pro/security/advisories/new

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Any suggested fix (optional)

We will acknowledge receipt of your report as soon as possible and work with you
to understand and address the issue. Once the vulnerability has been fixed, we
will coordinate a public disclosure as appropriate.

Thank you for helping keep this project and its users safe.
