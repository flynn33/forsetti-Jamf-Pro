## Historical material

Files under `docs/superpowers/`, `reports/`, and the root-level implementation and handoff reports are point-in-time engineering records. They may use the predecessor Jamf Dashboard name, old source paths, earlier module counts, or commands that are no longer current.

Use the current project documents above for present-day architecture, build, validation, licensing, and policy information. Historical material should remain unchanged unless a correction is needed to preserve the accuracy of the event it records.
