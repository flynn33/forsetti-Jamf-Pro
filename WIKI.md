# Forsetti Forsetti Jamf Pro Notes

This repository is organized as a Forsetti consumer application.

The app target owns the Forsetti Jamf Pro experience and links the public Forsetti products. The Forsetti framework source remains an external package/reference, not copied application source.

Feature views remain user-facing Forsetti Jamf Pro UI and are reached through the dedicated UI module route catalog. Feature and platform responsibilities are represented by Forsetti service modules and app-owned service adapters.
